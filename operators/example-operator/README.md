# example-operator — teaching artifact

This directory is a **synthetic, fully-worked example** produced by `/onboard`. It is
here so you can see what a completed `IMPRINT.md` looks like before you create your own.

**Delete this entire directory once you have run `/onboard` for your own slug.**

```
rm -rf operators/example-operator/
```

Nothing in this directory is wired to real credentials, real clients, or a real domain.
The operator slug (`example-operator`), the company name (`Acme Research Lab`), and the
domain (`acme-research.example.com`) are synthetic placeholders.

## What to do next

1. Run `/onboard` from the repo root.
2. Answer the guided questions for each Four-Cs layer.
3. Your `operators/<your-slug>/IMPRINT.md` will be written automatically.
4. Come back here and delete this directory.

The example swarm this operator activates lives at `swarms/example-research-swarm/` and
is similarly deletable — its own `CLAUDE.md` and `README.md` carry the same instruction.
